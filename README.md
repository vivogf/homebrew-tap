# vivogf/tap

Homebrew casks by vivogf.

```sh
brew tap vivogf/tap
brew trust vivogf/tap   # Homebrew asks you to trust third-party taps
brew install --cask vivogf/tap/threefingerminimize
brew install --cask vivogf/tap/softclick
```

| Cask | Description |
| --- | --- |
| [threefingerminimize](https://github.com/vivogf/ThreeFingerMinimize) | Minimize the focused window by swiping down with three fingers |
| [softclick](https://github.com/vivogf/SoftClick) | Softer haptic click for the built-in Force Touch trackpad |
